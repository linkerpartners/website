# 사례 넣는 법

사례 하나는 폴더 하나입니다. 사례 페이지(`cases.html`)와 홈의 사례 문단이 모두 이 폴더들에서 읽습니다. HTML은 고치지 않아도 됩니다.

## 새 사례 넣기

1. `_template` 폴더를 복사해 새 폴더를 만듭니다. 폴더 이름이 사례의 주소가 돼요(영문 소문자·숫자·하이픈. 예: `cosmetics-osaka` → `cases.html#case=cosmetics-osaka`).
2. **사진은 넣지 않습니다.** 목록 · 상세 맨 위 · 다음 사례 미리보기는 영문 브랜드 이름만 보이고, 상세 본문의 숫자 카드 · 그래프는 `metrics` · `timeline` · `services`에서 그려져요.
3. `case.json`을 채웁니다. 각 항목의 뜻은 아래 표에 있어요.
4. `index.json`의 `cases` 목록에 폴더 이름을 넣습니다. **목록의 순서가 화면의 순서**예요. 빼면 화면에서 사라져요(폴더는 남겨 둬도 됩니다). 홈 라이브러리에는 너무 빽빽해 보이지 않게 `index.json`의 `home` 목록(현재 8개)에 적은 사례만 나오고, `home`이 없으면 전부 나옵니다.

## case.json 항목

| 항목 | 뜻 |
|---|---|
| `id` | 폴더 이름과 같게 |
| `brand` | 홈 라이브러리에 보이는 브랜드 이름. **언어와 관계없이 영어(라틴 글자) 표기**(예: BAT · Nakai Shuzo). 한국어 · 일본어의 `title` · `short` · `summary` 안의 브랜드 이름도 영어로 씀 |
| `example` | 링커파트너스가 진행하지 않은 공개 사례면 `true`(상세 보기 아래쪽에 안내 문구. 카드에는 표시 없음). 실제 사례는 `false` |
| `route` | `kr_jp`(한국 → 일본) 또는 `jp_kr`(일본 → 한국). 거르기와 방향 표시에 씀 |
| `year` | 진행 연도 |
| `budget` | 프로젝트 금액(원). 화면에 언어별 통화로 바뀌어 나와요. 공개하지 않으려면 지우세요 |
| `services` | 사용한 서비스 id. `spot` `diagnostic` `logo` `web` `booking` `sns` `localization` `channel` `advisory` 가운데에서 |
| `sources` | 출처 링크 `[{ label, url }]`. 공개 사례에 씀(상세 보기 맨 아래에 "출처"로 나옴) |
| `metrics` | 숫자로 본 결과. `value`는 숫자만(원 · 엔 같은 금액 단위가 나라마다 다르면 `{ "ko": "4억+", "ja": "4,700万円+", "en": "₩400M+" }`처럼 언어별로), `label`은 그 숫자가 뜻하는 것(세 언어). **일본어 글은 원화 금액을 엔화로 바꿔 쓰고**(1원 = 0.118엔) 필요하면 괄호에 원화를 함께 적음 |
| `ko` / `ja` / `en` | 언어별 글. `client` 고객, `industry` 업종, `duration` 기간, `short` 홈 문단에 들어갈 짧은 이름, `title` 제목, `summary` 요약, `challenge` 과제, `approach` 한 일(목록), `result` 결과, `timeline` 일정(`when` · `what`), `deliverables` 결과물(목록) |

- 비워 둔 항목은 화면에 나오지 않아요. 예를 들어 `metrics`가 없으면 숫자 줄이 빠집니다.
- 일본어 · 영어를 아직 못 썼으면 그 언어에서는 한국어가 대신 나와요(`ja`, `en`을 통째로 지운 경우).
- 고객 이름과 숫자는 고객의 동의를 받은 범위만 씁니다.
